# FairFetch 5-minute demo talk track

1. Open **Publisher Dashboard → Overview** and explain checklist + KPI cards.
2. Go to **Domains**. Add a domain, open setup drawer, and explain DNS verification + paid-access subdomain delegation.
3. Go to **Pricing**. Enable Summarize/Full Display licenses, then create a hierarchy rule (AI client, page, directory, freshness).
4. Open **Demo Console**. Click **Seed demo workspace** and highlight generated IDs and API key.
5. Run **Simulate AI fetch** and show the receipt (transaction id + price).
6. Open **Transactions** to show the new record and CSV export.
7. Open **AI Team Dashboard** to show updated usage/spend and integration snippet.
8. Close with policy note: FairFetch licenses prohibit training usage.
